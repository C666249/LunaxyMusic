# V16 参数速查（后续细抠 UI 用）

## 封面波纹
文件：`app/src/main/java/com/xingyu/music/ui/VinylRecordView.java`

- `WAVE_COUNT = 5`：波纹圈数
- `r = min(w,h) * .418f`：圆盘可见尺寸
- `phase * .115f`：波纹最大基础扩散范围
- `visualBass`：控制扩张与粗细
- `visualBeat`：控制鼓点瞬时推开/加粗/变亮
- `basePresence`：常态波纹存在感

## UI 视觉 Token
文件：`app/src/main/java/com/xingyu/music/ui/Ui.java`

- `glass(...)`：绝大多数卡片/弹窗
- `tintedGlass(...)`：少量强调色卡片
- `primaryFill(...)`：主操作按钮
- `iconButton(...)`：全局图标按钮线宽/尺寸
- `applyRipple(...)`：按下反馈

## 歌词
文件：`MainActivity.java` + `ui/LyricLineView.java`

- 歌词视窗高度：258dp
- 手动拖动后恢复跟随：约 3.2 秒
- 默认渐变：`Ui.LYRIC_ICE_START` → `Ui.LYRIC_ICE_END`
- 当前句字号：16.2sp
- 普通句字号：14sp

这些都属于 UI 层，可继续单独调整，不需要碰播放核心。
