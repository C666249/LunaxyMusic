# V92.9.10 validation log

## Trigger / root cause

- User supplied a real Android Studio `:app:compileDebugJavaWithJavac` failure from V92.9.9.
- Failing source: `MainActivity.configureSystemSplashExit()` called `provider.getView()` where the callback parameter type is framework `android.window.SplashScreenView`.
- Android framework API contract: the exit listener receives `SplashScreenView` itself; it is a `FrameLayout`/View and exposes `remove()`, not `getView()`.
- Fix: animate the callback parameter (`splashView`) directly and keep `withEndAction(splashView::remove)`.
