## Review findings / fixes

1. Moonlight still reused dark-only fill/shader logic in the Home current-track halo and recommendation custom materials; dedicated light branches were added.
2. Recommendation material picker used very-low-alpha white strokes that effectively disappeared on a light sheet; changed to `contentSurface` / `tintedGlass`.
3. Standalone appearance control was structurally unrelated to Search; removed and merged with recommendation styling as `卡片 | 主题` contextual segmented actions.
4. Now Playing utility/transport controls were visually grey/static on Moonlight; added theme-aware semantic surfaces/icon colours and short semantic micro-interactions.
5. Play-mode state could update through the queue sheet without refreshing the full-player semantic surface; added `nowModeButton` synchronization.
6. Rapid micro-interactions cancel the current presentation animator before starting the next acknowledgement; Reduced Motion uses short alpha/state confirmation instead of spatial motion.
