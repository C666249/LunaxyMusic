## 本轮重点行为复核

- Root Tab 之间保持稳定横向空间语义，旧页/新页共同参与过渡。
- Tab `ACTION_DOWN` 即时响应；选中 pill 连续迁移。
- 快速连续点击取消当前 presentation animator，并从当前视觉状态 retarget，不排队。
- 每个 Tab 保存 root scroll 和支持的一层 detail 状态；reselect 当前 detail 返回 root。
- 跨 Tab 恢复 detail 时仍保持 lateral，same-tab detail 才使用 push/pop 深度语义。
- Appearance 默认 Deep，避免老用户在系统浅色环境升级后突然切换到 Moonlight。
- Deep/OLED/Moonlight/System、Reduced Motion、Reduced Transparency、主题源点 reveal 已接入 Shell。
- Reduced Motion 会停止/冻结持续星空、推荐材质、唱片装饰、Halo 漫游，并缩短状态型 motion；不会冻结业务状态。

## Android 构建状态（必须如实说明）

本交付容器未安装可用 Android SDK（`ANDROID_HOME` / `ANDROID_SDK_ROOT` 为空，也未发现可用 `android.jar`）。执行 Gradle wrapper 时，项目脚本尝试下载 Gradle 9.5.0，但 `curl` 明确返回 `Could not resolve host: services.gradle.org`，因此没有完成 Gradle 分发下载。

所以本轮**不能宣称 Gradle Sync / assembleDebug / assembleRelease / APK 构建成功**。裸 `javac` 对完整 Android 源码也不能替代 Android SDK 符号级编译；其中对既有 `OnBackInvokedCallback` method reference 的诊断经对照 V92.8.10 基线确认是缺 Android SDK 造成的类型解析假阳性，不作为新增源码错误处理。
